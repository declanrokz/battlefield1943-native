# Contributing

Start with one focused question and a reproducible observation. Label what is confirmed by instructions, confirmed by runtime tests, inferred, or still unknown.

For findings, record the game revision, guest addresses, relevant object offsets, input or configuration, bounded test duration, observed output and alternative explanations. Include no proprietary binary or asset files.

Keep reconstruction separate from reference pseudocode. A renamed decompile is not a validated replacement. Any replacement needs comparison against the original behavior, including guest memory, registers, indirect calls and error paths where relevant.

Current priorities are session event routing, spawn/camera state, graphics draw replay and reliable startup. Bots and frame-rate settings follow a validated gameplay foundation.
